ProbesMake documented prompt behavior real

  • Provide the documented prompt-input renderer default.

What must each owner prove before integration?

review gates

Focused proof

  • Reproduce the assigned red tests before editing production.
  • Fix the earliest invalid state, not the last assertion failure.
  • Run the complete owned test module and report every remaining failure.

Boundary proof

  • Update public types, exports, documentation, and affected callers together.
  • Use one implementation path; do not leave contiguous/stratified or permissive/strict alternatives.
  • Preserve unrelated diagnostics and behavior.

Integration proof

  • Root review of the full worktree diff before commit.
  • Ruff, ty, and the full suite green at each coherent merged wave.
  • Primary checkout unchanged during agent work; one committer on the target branch.
